    使用教程

    1. 配置 DeepSeek 或 MiniMax
    1. 先在对应服务商的开放平台创建 API Key。DeepSeek 的密钥不能用于 MiniMax，反之亦然。
    2. 打开顶部的「模型与插件设置」，选择预设（默认是 DeepSeek），粘贴 API Key。首次配置时保持预填的 Base URL 和模型名即可。
    3. 可先点「测试连接」，再点「保存模型」。返回聊天，新建或选择一个角色即可开始。

    对话需要将角色设定与必要的聊天上下文发送给选定的模型服务。

    2. 开关插件与故障恢复

    打开设置的「插件」区，按需启用或停用。列表会显示运行状态，以及插件接管或隐藏的默认功能。插件与 Write 在本机同进程运行，请只启用信任的代码。

    若插件导致启动或页面异常，先关闭服务，再在项目目录运行对应启动脚本进入安全模式（便携版也支持）：

    • Windows PowerShell：.\start.bat --safe-mode
    • macOS / Linux：sh ./start.sh --safe-mode

    回到设置停用有问题的插件，再关闭服务并正常启动。启动时设置环境变量 SAFE_MODE=1 也有同样效果；恢复后记得清除该变量。

    3. 找到和备份本地存档

    默认存在 Write 项目根目录的 data/。如果你设置过 DATA_DIR，则以指定目录为准。

    停止 Write 后，把整个存档目录复制到安全位置。恢复时也应先停止服务。备份可能包含聊天与 secrets.json 中的密钥，请不要公开分享或上传给 AI。

    4. 导入外部角色卡
    1. 在「模型与插件设置」启用 card-importer，再点顶部的「导入角色卡」。
    2. 选择 SillyTavern / Character Card V2 的 JSON 卡，或带角色数据的 PNG 卡。普通 PNG 图片不含可导入角色。
    3. 检查预览中的名字、人设和开场白，再确认创建本地角色。导入不会执行卡片内容，也不会覆盖已有角色。
    5. 用 AI 配置其他模型或编写插件

    可让 AI 先阅读项目里的 AGENTS.md 和 docs/plugin-dev.md，再参考 agent-openai-compat 或现有 CLI 插件填写配置、实现适配器。API Key 用环境变量，不要粘进提示词。

    编写扩展时可从 plugins/_template/ 复制模板，确认权限和插槽，只在审查代码后加入 DATA_DIR/plugins.json 白名单。运行 npm run check 和 npm test 验证。
